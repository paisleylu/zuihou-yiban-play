# 最后一班 · 手机版网页

**在线游玩：** [https://paisleylu.github.io/zuihou-yiban-play/](https://paisleylu.github.io/zuihou-yiban-play/)

在停电的午夜办公楼中寻找保险丝，修复设备并逃离。建议手机或平板横屏：左侧摇杆移动，右侧滑动转身，使用按钮互动、开关手电、慢走和冲刺。也支持键盘操作。

## 这个仓库是什么？

这是公开的 GitHub Pages 游戏网页，仅包含供浏览器运行的发布文件。开发项目在私有仓库 `paisleylu/zuihou-yiban`；其中 `手机版/dist/` 是这个网页的来源。Mac 电脑版是另一套版本，不会自动同步到本网页。

更新流程：先在开发项目修改并测试手机版，再把 `手机版/dist/` 的内容同步到本发布仓库、检查改动、提交并推送。GitHub Pages 完成构建后，在线地址才会更新。请不要将私钥、签名证书、私人截图或聊天内容放入本公开仓库。

本地预览：在此文件夹执行 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000/`。
